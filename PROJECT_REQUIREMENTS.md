# Project Requirements

This project is a classroom mini-project for demonstrating a Circular Doubly Linked List in a music playlist manager.

## Core objective
- Build a real circular doubly linked list instead of a Python list masquerading as one.
- Use it for playlist and playback navigation.
- Provide queue management, shuffle, and playback simulation.
- Create a Flask app with a simple frontend UI.

## Functional requirements
- Add, remove, reorder, and play tracks.
- Navigate using next and previous using linked-list pointers.
- Support repeat modes and queue-aware playback.
- Provide a visualization of the linked list and current/next/previous links.
- Test the linked-list and playlist logic.
- Document academic and implementation details.

## Technology
- Python 3
- Flask
- HTML5, CSS3, and vanilla JavaScript
- Pytest for automated tests
